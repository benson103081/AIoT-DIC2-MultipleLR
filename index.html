03 / REPRODUCIBLE WORKFLOW

讓每一個數字，都有來由。

切分 → 訓練 → 選模 → 評估

固定 seed 隨機切分 80% 訓練、20% 測試；每一折內重新擬合中位數／眾數填補、類別編碼與標準化。5-fold CV 比較方法、k 與正則化參數。Forward / Exhaustive 在每個訓練折內再使用 3-fold CV 選子集。

選模後以完整訓練集重訓，最後才計算測試集指標。推薦依 CV RMSE，平手優先較少欄位。選模 CV 本身仍有選擇偏差，不能當成無偏泛化估計。

如何解讀精簡與過度擬合？

較少欄位有助解釋與降低複雜度，但可能犧牲預測資訊。請一起查看訓練誤差、交叉驗證表現與折間變異；單次分數下降不足以證明過度擬合。小樣本下應另以重複切分或新資料驗證。

k 計算原始欄位，類別欄以群組選入；c 類編碼為 c−1 欄。Exhaustive 限最多 6 個候選欄、500 筆訓練資料；所有方法最多 8 個原始欄與 24 個編碼欄。模型計算在可取消的 Web Worker 中執行。

第二題實際執行 workflow：npm run workflow → 清理／切分／交叉驗證／訓練／評估 → mtcars 執行結果。完整說明見 README。
